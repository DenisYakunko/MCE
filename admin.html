Как публиковать изменения

  1. Добавь или отредактируй товары, новости, отзывы, баннеры прямо здесь. Всё автоматически сохраняется в черновик браузера — можно смело закрывать страницу.
  2. Нажми «⬇ Скачать все JSON» (или отдельный файл в нужной вкладке).
  3. Открой GitHub → репозиторий MCE → папку data.
  4. Нажми на имя файла (например products.json) → иконка карандаша → Replace file (или «Upload files» в папке) и загрузи скачанный файл.
  5. Закоммить изменения. Через 1–2 минуты сайт обновится.

Про фото

  1. Drag&drop в админке — картинка сожмётся и встроится прямо в JSON. Удобно для первых товаров, но JSON становится тяжёлым.
  2. Для большого каталога: загрузи файлы в папку uploads/ репозитория и вставь в поле путь вида uploads/products/cover.jpg.
  3. Рекомендуемые размеры: карточка 600×400, обложка новости 800×500, баннер 1600×600. Сжимай через tinypng.com.

Подсказки

  • Переносы строк в описаниях сохраняются (Enter = новая строка).
  • Бейджи: Хит / Новинка / Скидка — ставятся галочками.
  • «featured» — товар попадает в карусель «Разработки» на главной.
  • Блоки новости: текст, фото с подписью, цитата, видео — добавляются кнопками и двигаются стрелками ↑↓.
  • Кнопка «Сбросить черновик» в жёлтой плашке вернёт данные с сайта.
